
38. paket
 - untuk saat ini AXION Account sepenuhnya gratis.
   untuk menarik pengguna.
 - gratis selama 2 tahun jika pengguna bertambah perlahan.
   tapi 2 tahun juga bisa bertambah lama jika pengguna relatif kecil peningkatan.
 - gratis 2 tahun bisa menurun menjadi lebih singkat jika peningkatan jumlah pengguna yang drastis.

39. target user
 - 100+ user per bulan jika ramai
 - 100 user per 3 bulan jika relatif sepi

40. Recovery Code
 - harus 20 kode
 - berlaku: selamanya.
   tapi hanya 1 kali pakai per code. dan akan di hapus setelah code tersebut di gunakan.
   jadi hapus per code yang di gunakan. agar benar benar tidak valid setelah di gunakan.

41. feedback.
 - feedback di atasnamakan dengan username
  - pengguna OS apa situs atau web, versi aplikasi(jika menggunakan aplikasi), dll
  - bukan pesan email.
  - tapi tetap di simpan di D1 pesan. selama 5 hari.
  - Admin bisa melihat feedback user di dashboard Admin.
  - maksimal 2 feedback per hari.
 - github issues (rekomendasi)
  - pengguna OS apa situs atau web, versi aplikasi(jika menggunakan aplikasi), dll
  - tidak ada batasan feedback
  - username github.
  - tidak ada penghapusan
jadi. user punya 2 opsi untuk feedback.
