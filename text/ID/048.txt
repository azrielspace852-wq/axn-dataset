BAGIAN 13: ANTI-POLA ANDROID TINGKAT LANJUT
Anti-pola L1: Rahasia di BuildConfig.
Ciri: API key ditulis di build.gradle.kts.
Perbaikan: gunakan local.properties atau variabel lingkungan.

Anti-pola L2: Keystore di repositori.
Ciri: file .jks dilacak Git.
Perbaikan: hapus dari Git, rotasi keystore, gunakan manajer rahasia.

Anti-pola L3: google-services.json dilacak.
Ciri: file google-services.json dilacak Git.
Perbaikan: hapus dari Git, gunakan variabel lingkungan atau file lokal.

Anti-pola L4: Log verbose di build rilis.
Ciri: Log.d dipanggil di build rilis.
Perbaikan: gunakan wrapper logging yang menonaktifkan log di rilis.

Anti-pola L5: Debug diaktifkan di rilis.
Ciri: android:debuggable="true" di manifest rilis.
Perbaikan: hapus dari manifest rilis.

Anti-pola L6: Backup data sensitif.
Ciri: backup_rules.xml tidak mengecualikan token.
Perbaikan: kecualikan data sensitif dari backup.

Anti-pola L7: Tanpa mapping R8 yang diunggah.
Ciri: crash rilis tidak dapat dibaca.
Perbaikan: unggah mapping ke Play Console dan crash reporter.

Anti-pola L8: Tanpa baseline profile.
Ciri: startup lambat.
Perbaikan: buat baseline profile dan verifikasi dengan benchmark.

Anti-pola L9: Tanpa tes instrumen untuk alur utama.
Ciri: hanya ada tes unit.
Perbaikan: tambahkan tes instrumen untuk alur kritis.

Anti-pola L10: Tanpa tes unit untuk ViewModel.
Ciri: logika ViewModel tidak diuji.
Perbaikan: tambahkan tes unit dengan coroutines test.

Anti-pola L11: String ditulis langsung di Compose.
Ciri: Text("Halo") tanpa stringResource.
Perbaikan: gunakan stringResource.

Anti-pola L12: Tanpa contentDescription.
Ciri: Image tanpa contentDescription.
Perbaikan: tambahkan contentDescription atau null jika dekoratif.

Anti-pola L13: Ukuran sentuh terlalu kecil.
Ciri: tombol 24dp.
Perbaikan: gunakan minimal 48dp.

Anti-pola L14: Tanpa dukungan RTL.
Ciri: padding kiri-kanan tetap.
Perbaikan: gunakan start dan end.

Anti-pola L15: Tanpa lokalisasi.
Ciri: hanya ada strings.xml default.
Perbaikan: tambahkan values-b+xx untuk bahasa target.

Anti-pola L16: Dependensi api berlebihan.
Ciri: semua dependensi memakai api.
Perbaikan: gunakan implementation secara default.

Anti-pola L17: Modul api bergantung pada impl.
Ciri: feature/beranda/api bergantung pada feature/beranda/impl.
Perbaikan: hapus dependensi tersebut.

Anti-pola L18: Modul fitur bergantung pada modul fitur lain.
Ciri: feature/beranda bergantung pada feature/detail.
Perbaikan: gunakan core/navigasi untuk kontrak.

Anti-pola L19: Modul core bergantung pada fitur.
Ciri: core/ui bergantung pada feature/beranda.
Perbaikan: pindahkan kode ke modul yang tepat.

Anti-pola L20: Version code tidak naik.
Ciri: versionCode sama untuk dua rilis.
Perbaikan: naikkan versionCode secara otomatis di CI.

Anti-pola L21: Tag Git tidak cocok dengan versionName.
Ciri: tag v1.0.0 tetapi versionName 1.0.1.
Perbaikan: sinkronkan tag dan versionName.

Anti-pola L22: CHANGELOG tidak diperbarui.
Ciri: rilis tanpa catatan perubahan.
Perbaikan: perbarui CHANGELOG dan dist/catatan-rilis/.

Anti-pola L23: Rollback tanpa rencana.
Ciri: tidak ada dokumentasi rollback.
Perbaikan: tulis rencana rollback di docs/rollback.md.

Anti-pola L24: Feature flag tanpa default.

Perbaikan: tetapkan default di FiturFlagDefault.kt.

Anti-pola L25: Feature flag tanpa pembersihan.

Perbaikan: hapus feature flag setelah fitur stabil.

Anti-pola L26: Remote config tanpa validasi.
Ciri: nilai remote config dipakai langsung.
Perbaikan: validasi nilai sebelum dipakai.

Anti-pola L27: Analytics tanpa persetujuan.
Ciri: analytics berjalan sebelum persetujuan.
Perbaikan: hormati persetujuan pengguna.

Anti-pola L28: Crash reporter tanpa deobfuscation.

Anti-pola L29: Build cache tidak diaktifkan.

Anti-pola L30: Tes instrumen dijalankan di setiap commit tanpa sharding.
