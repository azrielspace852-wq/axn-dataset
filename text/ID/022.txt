APA ITU DNS
DNS atau Domain Name System adalah sistem penamaan terdesentralisasi yang menerjemahkan nama domain yang mudah diingat menjadi alamat IP yang dipahami mesin.
DNS membuat pengguna dapat membuka situs dengan mengetik contoh.com alih-alih angka seperti 93.184.216.34.
DNS juga menyimpan jenis informasi lain seperti lokasi server surat, lokasi layanan, dan kunci keamanan.
Fungsi paling dasar DNS adalah menjadi buku telepon global yang selalu dapat dicari.
DNS bekerja berlapis sehingga tidak ada satu titik pusat tunggal yang menyimpan seluruh nama dunia.
Desain terdistribusi membuat DNS tahan terhadap gangguan lokal.
DNS merupakan protokol aplikasi yang berjalan di atas UDP dan TCP pada port 53.
DNS juga dapat berjalan melalui kanal terenkripsi seperti HTTPS dan TLS.
Tanpa DNS, infrastruktur internet modern menjadi tidak manusiawi untuk dipakai.
DNS bukan layanan penyimpanan halaman web, melainkan layanan penamaan dan pemetaan.
DNS menjawab pertanyaan tentang nama, bukan menyajikan isi.
Banyak kegagalan yang terasa seperti situs mati sebenarnya adalah kegagalan DNS.
Memahami DNS membantu mendiagnosis masalah jaringan dengan lebih cepat.
DNS menjadi jembatan antara bahasa manusia dan bahasa jaringan.
DNS juga menopang fungsi routing, keamanan email, dan penyeimbangan beban.

DNS memperkenalkan gagasan pohon nama berjenjang dari bawah ke atas.
