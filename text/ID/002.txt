1. PENGERTIAN UMUM
HTML adalah singkatan dari HyperText Markup Language, yaitu bahasa markup standar yang digunakan untuk membuat dan menyusun halaman web yang ditampilkan di browser [reference:0]. HTML bukan bahasa pemrograman dalam arti memiliki logika dan komputasi, melainkan bahasa penanda (markup) yang mendeskripsikan struktur dan konten dokumen, seperti judul, paragraf, tautan, gambar, tabel, dan formulir.

HTML menggunakan serangkaian "tag" atau penanda untuk membungkus bagian-bagian konten sehingga browser dapat memahami peran setiap bagian. Misalnya, teks yang dibungkus dengan `<h1>` dianggap sebagai judul utama, sedangkan teks di dalam `<p>` dianggap sebagai paragraf. HTML menjadi fondasi dari hampir semua halaman web yang ada di internet [reference:1].

2. SEJARAH, PENCIPTA, DAN ASAL USUL
HTML diciptakan oleh Sir Timothy John "Tim" Berners-Lee, seorang ilmuwan komputer berkebangsaan Inggris yang lahir pada 8 Juni 1955 [reference:2]. Pada saat itu, Berners-Lee bekerja sebagai insinyur perangkat lunak di CERN (Organisasi Eropa untuk Riset Nuklir), sebuah laboratorium fisika partikel di dekat Jenewa, Swiss [reference:3][reference:4].

Asal Negara: Swiss (CERN, Jenewa), oleh pencipta berkebangsaan Inggris [reference:5].
Tahun Diciptakan: Konsep dimulai pada 1989, pengembangan pada 1990, dan rilis publik pertama pada 1991 [reference:6].

Pada Maret 1989, Berners-Lee menulis proposal berjudul "Information Management: A Proposal" yang menguraikan ide sistem berbagi informasi berbasis hypertext melalui internet [reference:7]. Proposal ini awalnya tidak langsung diterima, tetapi pada September 1990 ia mulai mengembangkan idenya [reference:8]. Dalam proses tersebut, ia menciptakan HTML sebagai bahasa untuk membuat halaman web, serta HTTP (HyperText Transfer Protocol) untuk mentransfer data antara server dan pengguna [reference:9]. Pada 6 Agustus 1991, situs web pertama di dunia, "The World Wide Web Project", resmi dipublikasikan dan dapat diakses di alamat info.cern.ch [reference:10][reference:11].

3. SEJARAH VERSI HTML
Sejak kemunculannya, HTML mengalami beberapa kali evolusi versi:
- HTML (1991–1992): Versi awal yang sangat sederhana, hanya mendukung teks, judul, paragraf, dan tautan dasar.
- HTML 2.0 (1995): Standar pertama yang disepakati secara luas, menambahkan formulir dan elemen seperti `<form>`, `<input>`, serta tabel dasar.
- HTML 3.2 (1997): Menambahkan fitur seperti tabel yang lebih kompleks, applet, dan penulisan script sederhana.
- HTML 4.01 (1999): Versi yang sangat stabil dan lama digunakan, memperkenalkan pemisahan yang lebih jelas antara struktur dan presentasi (meskipun CSS belum sepenuhnya dominan).
- XHTML (2000): Upaya untuk menerapkan HTML dengan aturan XML yang lebih ketat. XHTML 1.0 dan 1.1 sempat populer, tetapi kurang fleksibel dibandingkan HTML biasa.
- HTML5 (2014): Lompatan besar yang memperkenalkan elemen semantik (`<header>`, `<nav>`, `<article>`, `<footer>`), dukungan audio/video native (`<audio>`, `<video>`), canvas, penyimpanan lokal, dan API JavaScript yang lebih kaya [reference:12].

Sejak 28 Mei 2019, W3C secara resmi mengumumkan bahwa WHATWG HTML Living Standard adalah satu-satunya versi HTML yang berlaku [reference:13]. Artinya, HTML tidak lagi memiliki nomor versi resmi seperti "HTML5.2" atau "HTML6". Spesifikasi HTML kini diperbarui secara berkelanjutan (living standard) dan versi terbarunya dapat dilihat di html.spec.whatwg.org [reference:14]. Meskipun demikian, istilah "HTML5" tetap populer di kalangan pengembang dan sering merujuk pada kumpulan teknologi web modern (HTML Living Standard, CSS, JavaScript API) [reference:15].

4. SINTAKS DAN CONTOH BAHASA
Dokumen HTML disusun dari elemen-elemen yang ditandai dengan tag pembuka dan penutup. Berikut adalah struktur dasar dokumen HTML5:

```html
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Halaman Contoh</title>
</head>
<body>

    <header>
        <h1>Selamat Datang di Website Saya</h1>
    </header>

    <nav>
        <ul>
            <li><a href="#beranda">Beranda</a></li>
            <li><a href="#tentang">Tentang</a></li>
        </ul>
    </nav>

    <main>
        <section id="beranda">
            <h2>Beranda</h2>
            <p>Ini adalah paragraf pertama saya dalam <strong>HTML</strong>.</p>
            <img src="gambar.jpg" alt="Deskripsi gambar">
        </section>

        <section id="tentang">
            <h2>Tentang</h2>
            <p>HTML digunakan untuk menyusun struktur halaman web.</p>
        </section>
    </main>

    <footer>
        <p>&copy; 2026 Azriel</p>
    </footer>

</body>
</html>
```

Penjelasan singkat elemen-elemen utama:

· <!DOCTYPE html>: Mendeklarasikan bahwa dokumen menggunakan HTML5 (Living Standard) .
· <html>: Elemen akar yang membungkus seluruh dokumen.
· <head>: Berisi metadata, judul halaman, charset, dan tautan ke stylesheet atau script.
· <body>: Berisi konten yang terlihat oleh pengguna.
· <h1> hingga <h6>: Heading atau judul dengan tingkat kepentingan yang berbeda.
· <p>: Paragraf teks.
· <a>: Tautan (anchor) ke halaman lain atau bagian dalam halaman.
· <img>: Menampilkan gambar.
· <ul>, <ol>, <li>: Daftar tidak berurutan, berurutan, dan item daftar.
· <section>, <article>, <header>, <footer>, <nav>, <main>: Elemen semantik untuk menyusun struktur halaman dengan makna yang jelas.

5. KEGUNAAN HTML
   HTML memiliki kegunaan utama sebagai berikut:

· Membangun Struktur Halaman Web: HTML mendefinisikan kerangka dasar halaman, termasuk judul, paragraf, daftar, tabel, gambar, dan tautan.
· Menghubungkan Halaman (Hyperlink): Melalui elemen <a>, HTML memungkinkan navigasi antarhalaman web, yang menjadi inti dari World Wide Web.
· Menyematkan Media: HTML5 memungkinkan penyematan audio, video, dan grafik (canvas) secara langsung tanpa plugin tambahan.
· Formulir Interaktif: Elemen <form>, <input>, <select>, dan <textarea> memungkinkan pengumpulan data dari pengguna.
· Fondasi untuk CSS dan JavaScript: HTML menyediakan struktur yang kemudian dihias oleh CSS dan diberi perilaku interaktif oleh JavaScript. Tanpa HTML, CSS dan JavaScript tidak memiliki "kerangka" untuk bekerja.
· Aksesibilitas dan SEO: HTML semantik membantu mesin pencari memahami konten dan membantu pembaca layar (screen reader) menavigasi halaman.

6. KELEBIHAN DAN KEKURANGAN HTML

Kelebihan HTML:

· Mudah Dipelajari: Sintaks HTML relatif sederhana dan ramah pemula, sehingga menjadi bahasa pertama yang dipelajari banyak pengembang web .
· Open Source dan Gratis: HTML adalah standar terbuka yang dapat digunakan tanpa biaya lisensi .
· Didukung Semua Browser: Semua browser modern (Chrome, Firefox, Safari, Edge) mendukung HTML .
· Komunitas dan Sumber Daya Melimpah: Dokumentasi, tutorial, dan forum diskusi tentang HTML sangat banyak dan mudah diakses .
· Mudah Diintegrasikan: HTML dapat dengan mudah digabungkan dengan bahasa backend seperti PHP, Node.js, dan Python, serta dengan CSS dan JavaScript .
· Ringan dan Cepat: File HTML berukuran kecil dan cepat dimuat oleh browser.

Kekurangan HTML:

· Hanya untuk Konten Statis: HTML murni tidak dapat membuat halaman yang dinamis (misalnya, konten yang berubah berdasarkan input pengguna atau data dari database). Untuk itu, diperlukan JavaScript atau bahasa backend .
· Tidak Memiliki Logika: HTML tidak mendukung percabangan, perulangan, atau operasi matematika. Semua halaman harus dibuat secara terpisah atau dihasilkan oleh server .
· Keterbatasan Presentasi: HTML bukan alat desain yang kuat; untuk tata letak dan gaya yang kompleks, CSS sangat diperlukan.
· Perbedaan Dukungan Fitur: Beberapa fitur HTML terbaru mungkin belum didukung sepenuhnya oleh semua browser lama, meskipun browser modern umumnya sudah kompatibel .

7. STATUS DAN VERSI TERKINI
   Saat ini, HTML bukan lagi bahasa dengan nomor versi statis. Sejak 2019, WHATWG HTML Living Standard menjadi spesifikasi tunggal yang terus diperbarui . Versi terbaru dari spesifikasi ini dapat dilihat langsung di html.spec.whatwg.org, dan pembaruan dilakukan secara berkelanjutan seiring dengan perkembangan web . Istilah "HTML5" tetap digunakan secara luas untuk merujuk pada generasi HTML modern yang mencakup elemen semantik, media native, dan API JavaScript yang kaya, tetapi secara teknis, tidak ada lagi "HTML6" atau "HTML5.3" dalam pengertian standar formal.
8. KESIMPULAN
   HTML adalah bahasa markup fundamental yang menjadi tulang punggung World Wide Web. Diciptakan oleh Tim Berners-Lee di CERN pada awal 1990-an, HTML telah berevolusi dari bahasa sederhana dengan sedikit tag menjadi standar hidup (living standard) yang kaya akan elemen semantik dan kemampuan multimedia. HTML mudah dipelajari, gratis, dan didukung oleh semua browser, menjadikannya pintu gerbang bagi siapa pun yang ingin membangun halaman web. Meskipun HTML memiliki keterbatasan dalam hal logika dan konten dinamis, kombinasi HTML dengan CSS dan JavaScript menghasilkan pengalaman web yang lengkap dan interaktif. Memahami HTML adalah langkah pertama yang esensial dalam perjalanan pengembangan web.
