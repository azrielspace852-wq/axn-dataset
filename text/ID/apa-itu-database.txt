APA ITU DATABASE
Database atau basis data adalah kumpulan data yang disimpan secara terstruktur agar dapat dicari, dikelola, dan diperbarui dengan efisien.
Basis data bukan sekadar tumpukan file, melainkan sistem yang memahami hubungan antar data.
Kata kunci dari database adalah keteraturan, akses cepat, dan konsistensi.
Tanpa database, aplikasi harus mengelola sendiri tata letak data pada media penyimpanan.
Dengan database, logika penyimpanan dan pengambilan data dipisahkan dari kode aplikasi.
Database menjadi fondasi bagi hampir semua aplikasi digital modern, dari login hingga pembayaran.
Tujuan utama database adalah memastikan data tersedia, akurat, dan terlindungi.
Database memungkinkan banyak pengguna mengakses data yang sama secara bersamaan tanpa saling merusak.
Database menyediakan bahasa kueri untuk menanyakan data tanpa perlu tahu letak fisiknya.
Database menyimpan bukan hanya nilai data, tetapi juga aturan mengenai data tersebut.
Aturan itu meliputi tipe data, batasan nilai, relasi antartabel, dan izin akses.
Database juga menyimpan metadata yang menjelaskan isi dan struktur data.
Metadata membuat sistem dapat memvalidasi dan mengoptimalkan kueri secara otomatis.
Sebuah basis data dapat menampung data numerik, teks, gambar, lokasi, hingga vektor embedding.
Skala database sangat luas, dari satu file di saku hingga ribuan node di pusat data.
DATABASE MANAGEMENT SYSTEM
DBMS adalah perangkat lunak yang menyediakan akses, keamanan, dan manajemen terhadap database.
DBMS berperan sebagai perantara antara aplikasi dan penyimpanan fisik data.
Tanpa DBMS, programmer harus menulis sendiri logika file, buffer, indeks, dan pemulihan.
DBMS mengatur eksekusi kueri, pengelolaan transaksi, dan pemulihan pasca kegagalan.
DBMS menyediakan katalog sistem sebagai daftar isi seluruh skema dan objek.
DBMS memisahkan mekanisme penyimpanan dari cara pengguna meminta data.
Contoh DBMS relasional adalah PostgreSQL, MySQL, MariaDB, Oracle Database, dan SQL Server.
Contoh DBMS non-relasional adalah MongoDB, Redis, Cassandra, dan Neo4j.
Ada juga DBMS multi-model yang dapat melayani beberapa model data sekaligus.
DBMS berbeda dengan bahasa kueri; SQL adalah bahasa, DBMS adalah sistem pelaksananya.
DBMS menentukan seberapa kuat fitur transaksi, indeks, replikasi, dan keamanan yang tersedia.
Kompeten memilih DBMS berarti memahami beban kerja, bukan sekadar nama produk.
SEJARAH DATABASE
Era paling awal penyimpanan digital menggunakan file datar tanpa struktur relasi.
Pengelolaan file manual membuat duplikasi data dan inkonsistensi sangat mudah terjadi.
Model hierarki muncul lebih dulu dengan struktur seperti pohon yang berakar pada data induk.
Model jaringan dikembangkan untuk mengatasi keterbatasan hierarki dengan relasi yang lebih bebas.
E. F. Codd memperkenalkan model relasional melalui makalahnya pada tahun 1970.
Model relasional menyimpan data dalam tabel dan menanyakan relasi lewat nilai, bukan alamat.
Pendekatan ini membebaskan aplikasi dari detail penyimpanan fisik yang rumit.
SQL berkembang dari bahasa SEQUEL di IBM sebagai antarmuka untuk basis data relasional.
IBM System R menjadi salah satu proyek awal yang membuktikan konsep relasional dapat dipakai.
Oracle menjadi basis data relasional komersial yang sangat berpengaruh sejak akhir 1970-an.
MySQL dan PostgreSQL membawa model relasional ke ekosistem sumber terbuka.
LedgerBook dan sistem pembukuan digital menunjukkan database telah dipakai jauh sebelum web.
Era web meningkatkan kebutuhan database yang dapat menangani trafik tinggi.
Perkembangan ini memicu lahirnya keluarga NoSQL pada awal 2000-an.
Cloud mendorong model database terkelola yang mengurangi beban administrasi manual.
Basis data kini menjadi komponen penting dalam arsitektur kecerdasan buatan.

NORMALISASI DAN DENORMALISASI
Normalisasi adalah proses menyusun tabel agar bebas anomali dan duplikasi.
Normalisasi pertama menuntut nilai atomik dan tidak ada kelompok data ganda.
Normalisasi kedua menuntut setiap atribut non-kunci bergantung pada kunci utuh.
