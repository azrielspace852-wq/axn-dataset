3. penggunaan gemini-embedding-2
 - di gunakan untuk memory external jika konteks per request sangat panjang
 - sebagai "jembatan" untuk model teks only agar bisa melihat, dan mendengar, dsb.
 - deteksi konten

4. konten yang di larang secara eklips.
 - pornografi
 - kekerasan
 - perbuatan melanggar hukum/kriminal
jika mebgandung konten di atas. maka request harus di hentikan dan kirim pesan jika konten melanggar kebijakan dalam bahasa english, dan harus di dokumentasikan.

5. memory
kita tidak menyediakan memory per percakapan.
tapi per request. dan setelah request complete. tidak ada memory yang tersimpan.

6. database
 - turso 1 : untuk simpan vector gemini-embedding-2. kapasitas 4.85GB (bersih 4.83GB)
 - turso 2 : knowladge AI kapasitas 150MB (bersih 100MB)
 - firestore : untuk menyimpan API KEY, dan queues.

7. hosting & backend
 - backend : cloudflare worker
 - frontend : cloudflare pages

8. CPU Time & Durable Object
mengenai keterbatasan CPU Time hanya 10ms. kita harus bisa memaksimalkan nya.
dan setahu saya 10ms adalah waktu eksekusi kode. bukan menunggu response.
 - cloudflare tidak mengizimkan menulis/mengatur CPU Time walaupun 10ms atau di bawah 10ms
 - Durable Object di gunakan untuk eksekusi kode saat Ada request pemanggilan AI.
