APA ITU SERVER
Server adalah komputer yang dirancang untuk menyediakan layanan kepada komputer lain melalui jaringan.
Kata server berasal dari fungsi utamanya, yaitu melayani permintaan dari klien.
Server dapat berupa perangkat keras fisik, perangkat lunak, atau kombinasi keduanya.
Dalam pengertian teknis, server adalah proses atau sistem yang menjawab permintaan dari klien.
Dalam pengertian komersial, server adalah mesin khusus yang bekerja terus-menerus untuk melayani banyak pengguna.
Server umumnya beroperasi 24 jam sehari tanpa henti.
Server jarang digunakan untuk keperluan interaktif langsung seperti membuka browser untuk berselancar.
Server biasanya tidak memiliki monitor yang terhubung terus-menerus.
Server diakses dari jarak jauh melalui koneksi jaringan.
Server dapat melayani satu klien atau jutaan klien pada saat yang sama.
Peran server berbeda dengan workstation karena prioritasnya adalah ketersediaan layanan.
Server menjadi tempat aplikasi berjalan agar dapat diakses secara terpusat.
Server dapat menjadi pemegang otoritas dalam satu jaringan, misalnya domain controller.
Server dapat menjadi tempat penyimpanan dokumen bersama.
Server dapat menjadi penjaga basis data yang diakses banyak aplikasi.
Server dapat menjadi jembatan antara pengguna dan sumber daya komputasi.
Server dapat menjalankan banyak layanan sekaligus pada satu mesin.
Server memiliki filosofi desain yang berbeda dari komputer pribadi.
Desain server mengutamakan reliabilitas, bukan fitur multimedia.
Desain server mengutamakan throughput berkelanjutan, bukan puncak performa sesaat.
Desain server mengutamakan uptime, bukan kemudahan upgrade gaming.
Server dapat berupa tower, rack, blade, atau microserver.
Server dapat berupa instance virtual yang berjalan di dalam cloud.
Server dapat berupa container yang dibagikan di host bersama.
Server dapat berupa fungsi tanpa server yang dijalankan sesuai permintaan.
Konsep server telah ada sejak era mainframe dan terminal.
Konsep server modern melebur dengan cloud, virtualisasi, dan edge computing.
Server adalah tulang punggung internet dan layanan digital.
Tanpa server, aplikasi web, email, streaming, dan basis data tidak akan tersedia.
Server adalah titik sentral yang membuat layanan digital dapat diandalkan.

KOMPONEN PERANGKAT KERAS SERVER
Prosesor server dirancang untuk menangani banyak thread secara paralel.
CPU server umumnya memiliki jumlah core lebih banyak dibanding CPU desktop.
Intel Xeon dan AMD EPYC adalah contoh prosesor server kelas atas.
ARM server seperti Ampere Altra menunjukkan tren arsitektur hemat energi.
Prosesor server mendukung instruksi untuk virtualisasi secara perangkat keras.
RAM ECC menjadi ciri khas server karena mampu mendeteksi dan memperbaiki error memori.
Kapasitas RAM server bisa ratusan gigabita hingga terabita.
Kecepatan RAM server diukur dari bandwidth dan latensi.
Motherboard server menggunakan chipset yang mendukung banyak peripheral.
Motherboard server sering memiliki slot PCIe lebih banyak daripada PC biasa.
Storage server dapat memakai HDD, SSD SATA, SSD NVMe, atau kombinasi keduanya.
SSD server dirancang untuk endurance tinggi dengan TBW besar.
RAID controller mengatur beberapa disk menjadi satu volume tahan gagal.
RAID 0, 1, 5, 6, dan 10 adalah konfigurasi yang paling umum dipakai.
RAID hardware memakai kartu khusus dengan cache dan backup daya.
PSU server umumnya redundant sehingga jika satu mati, server tetap hidup.
PSU server dilengkapi fitur hot-swap agar dapat diganti tanpa mematikan mesin.
GPU server digunakan untuk komputasi paralel, AI, dan rendering.
NVIDIA A100, H100, dan L40S adalah contoh GPU untuk beban kerja berat.
NIC server dapat memiliki beberapa port dengan kecepatan 1 hingga 200 gigabit per detik.
NIC dengan fitur SR-IOV mendukung virtualisasi jaringan.
HBA host bus adapter menghubungkan server ke SAN atau storage eksternal.
Kabel fiber optik sering dipakai di lingkungan data center untuk jarak jauh.
BMC adalah controller terpisah untuk manajemen server dari jarak jauh.
IPMI, iDRAC, dan iLO adalah contoh sistem manajemen bawaan server.
Kipas server dirancang tahan panas dan berputar lebih kuat.
Heatsink server memiliki luas permukaan besar untuk membuang panas.
Rackmount adalah bentuk fisik yang dapat dipasang di rak 19 inci.
Blade server adalah kartu yang masuk ke chassis bersama.
Microserver adalah bentuk kecil dengan kepadatan tinggi.
Tower server memiliki bentuk mirip PC tetapi dirancang untuk operasi 24 jam.

Memory bandwidth menjadi faktor penting untuk aplikasi analitik.
Kapasitas PCIe lane menentukan seberapa banyak perangkat dapat dipasang.
Form factor server memengaruhi tata letak di rak dan sistem pendingin.

Dimensi server diukur dengan satuan U, yaitu satu unit racksetinggi sekitar 4,45 sentimeter.
Server 1U tipis dan hemat ruang, server 2U lebih lega, server 4U dapat menampung banyak disk.
Sled adalah unit yang dapat digeser masuk dan keluar dari rack.
Konektor power server memakai C13, C14, C19, atau C20 tergantung daya.

Panel depan server sering memiliki LED status, tombol, dan port konsol.

SERVER DAN HIGH AVAILABILITY
High availability berarti sistem tetap berjalan meski sebagian komponen gagal.
Redundansi电源 adalah salah satu contoh paling umum.
Network interface bonding menggabungkan dua NIC menjadi satu link tahan gagal.
RAID melindungi data dari kegagalan satu atau lebih disk.
Failover cluster memindahkan layanan ke node lain saat satu node mati.
Load balancer mendistribusikan permintaan ke beberapa server aktif.
Active-active memungkinkan semua server melayani trafik pada saat yang sama.
Active-passive membiarkan server kedua menganggur hingga yang pertama gagal.
Health check menentukan kapan sebuah node dianggap sehat.
Quorum memastikan keputusan cluster tidak ambigu saat node hilang.
Data replication membuat salinan tersedia di lokasi lain.
Synchronous replication menjaga konsistensi ketat tetapi lebih lambat.
Asynchronous replication lebih cepat tetapi dapat kehilangan data saat bencana.
Multi-zone deployment mengurangi risiko kegagalan satu zona ketersediaan.
Multi-region deployment melindungi dari kegagalan wilayah.
Blue-green deployment menyediakan lingkungan cadangan yang siap diambil alih.
Canary deployment memverifikasi perubahan pada sebagian kecil trafik.
Rolling update memperbarui node satu per satu tanpa menghentikan layanan.
Disaster recovery plan menentukan prosedur saat sistem utama gagal total.
RPO menentukan seberapa banyak data boleh hilang dalam bencana.
RTO menentukan seberapa cepat layanan harus dipulihkan.
Chaos engineering menguji ketahanan sistem dengan menyuntik kegagalan.
Load test memverifikasi kemampuan sistem menghadapi trafik puncak.
Monitoring terus-menerus menjadi bagian tak terpisahkan dari HA.
Runbook menjadi panduan saat insiden terjadi.
PERBEDAAN SERVER DENGAN PC BIASA
Server dan PC berbagi komponen dasar, tetapi tujuan desain mereka berbeda.
PC dioptimalkan untuk satu pengguna interaktif, server untuk banyak klien simultan.
PC jarang berjalan 24 jam, server dirancang untuk beroperasi terus-menerus.
PC sering memiliki GPU gaming, server lebih sering memakai GPU komputasi.
PC jarang menggunakan RAM ECC, server hampir selalu memakai ECC.
PC biasanya memiliki satu power supply, server sering memiliki dua PSU redundant.
PC jarang memiliki remote management card, server umumnya punya BMC atau iDRAC.
PC jarang mendukung hot-swap, server sering mendukung penggantian disk dan power tanpa restart.
PC jarang mendukung prosesor multi-socket, server bisa memasang dua CPU atau lebih.
PC jarang memiliki ratusan core, server kelas enterprise dapat memuat hingga ratusan core.
PC menggunakan Windows, macOS, atau Linux desktop, server memakai varian sistem operasi tanpa GUI.
PC jarang memakai RAID hardware, server sering memakai RAID untuk perlindungan data.
PC jarang memakai koneksi fiber, server sering memakai 10 gigabit ke atas.
PC dirancang untuk responsivitas tinggi pada satu tugas, server untuk throughput banyak tugas.
PC jarang mendukung konfigurasi jarak jauh tingkat firmware, server dirancang untuk itu.
PC jarang diletakkan di rak data center, server memang dirancang untuk rak.
PC jarang membutuhkan sertifikat keandalan tingkat industri, server sering membutuhkannya.
PC jarang dilengkapi sistem pendinginan berlapis, server memakai airflow terkontrol.
PC jarang memakai kabel daya ganda ke PDU terpisah, server sering memakainya.
PC jarang memiliki garansi dengan dukungan onsite, server sering menawarkan itu.
PC lebih murah untuk penggunaan harian, server lebih mahal karena fitur tahan gagal.
PC cocok untuk gaming, editing video, dan pekerjaan kantor, server cocok untuk hosting dan layanan.
PC jarang memiliki audit trail hardware, server dapat mencatat kejadian dari BMC.
PC jarang mendukung virtualisasi tingkat produksi, server dirancang sebagai host VM.
PC jarang diukur dalam U, server diukur dalam U untuk rak.
Perbedaan ini menegaskan bahwa server bukan PC yang lebih mahal, melainkan kelas mesin berbeda.
PERBEDAAN SERVER DENGAN SUPERKOMPUTER
Server melayani banyak klien dengan throughput dan keandalan.
Supercomputer memusatkan daya komputasi untuk satu tugas ilmiah yang sangat besar.
Server umumnya tersusun dari unit yang berdiri sendiri dengan tugas berbeda.
Supercomputer terdiri dari puluhan ribu node yang bekerja dalam satu aplikasi paralel.
Server sering menangani beban kerja heterogen, supercomputer menangani beban kerja homogen.
Server berfokus pada latensi rendah untuk banyak permintaan kecil.
Supercomputer berfokus pada throughput maksimum untuk satu perhitungan sangat panjang.
Server menggunakan jaringan gigabit atau 25 gigabit Ethernet.
Supercomputer menggunakan interkoneksi khusus seperti InfiniBand, Slingshot, atau NVLink.
Server dapat dioperasikan di rak kecil hingga data center sedang.
Supercomputer menempati ruang khusus dengan pendinginan masif.
Supercomputer diukur dalam FLOPS puncak dan efisiensi daya.
Server jarang diukur hanya dengan FLOPS, tetapi juga dengan request per detik.
Supercomputer membutuhkan software paralel khusus seperti MPI.
Server jarang memerlukan MPI karena beban kerjanya tidak seberat itu.
Supercomputer sering dipakai untuk simulasi iklim, fisika partikel, genomik, dan kriptografi.
Server dipakai untuk web, email, basis data, dan aplikasi bisnis.
Supercomputer jarang dipakai untuk melayani klien publik karena biayanya terlalu tinggi.
Supercomputer sering menjadi milik pemerintah atau institusi penelitian besar.
Server dapat ditemui di banyak kantor kecil dan menengah.
Perbedaan arsitektur utama adalah supercomputer mengorbankan fleksibilitas demi kekuatan satu aplikasi.
Perbedaan arsitektur server mengorbankan performa puncak demi keandalan dan skalabilitas multi-tenan.
Server dan supercomputer dapat berbagi komponen seperti CPU, RAM, dan PCIe.
Server tidak dirancang untuk komunikasi antar-node yang sangat cepat.
Supercomputer dirancang agar ribuan node dapat berkoordinasi dalam milidetik.
Keduanya memiliki filosofi berbeda dalam hal bagaimana tugas dipecah dan didistribusikan.
