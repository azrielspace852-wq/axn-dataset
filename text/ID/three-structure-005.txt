BAGIAN 10: ANTI-POLA STRUKTUR ANDROID
Anti-pola Android A1: Kode di folder res/.
Ciri: file .kt atau .java berada di res/.
Masalah: AGP tidak akan mengompilasi dengan benar.
Perbaikan: pindahkan ke java/ atau kotlin/.

Anti-pola Android A2: Resource di folder java/.
Ciri: file .xml layout berada di java/.
Masalah: resource tidak dikenali.
Perbaikan: pindahkan ke res/.

Anti-pola Android A3: Manifest ganda tanpa alasan.
Ciri: ada AndroidManifest.xml di banyak tempat tanpa kebutuhan flavor.
Masalah: membingungkan, rawan konflik merge.
Perbaikan: pertahankan manifest utama dan manifest flavor yang diperlukan.

Anti-pola Android A4: String ditulis langsung di kode.
Ciri: "Halo" ditulis langsung di file .kt.
Masalah: sulit diterjemahkan, sulit diubah.
Perbaikan: pindahkan ke strings.xml.

Anti-pola Android A5: Dimensi ditulis langsung di layout.
Ciri: 16dp ditulis langsung di banyak layout.
Masalah: sulit dikonsistenkan.
Perbaikan: gunakan dimens.xml.

Anti-pola Android A6: Warna ditulis langsung di layout.
Ciri: #FF0000 ditulis langsung di layout.
Masalah: sulit diubah, tidak mendukung tema.
Perbaikan: gunakan colors.xml dan referensi.

Anti-pola Android A7: File besar di satu Activity.
Ciri: MainActivity.kt berisi ratusan baris.
Masalah: sulit diuji, sulit dirawat.
Perbaikan: pindahkan logika ke ViewModel, use case, repositori.

Anti-pola Android A8: Logika bisnis di Activity atau Fragment.
Ciri: aturan bisnis berada di Activity.
Masalah: sulit diuji tanpa perangkat.
Perbaikan: pindahkan ke ViewModel atau domain.

Anti-pola Android A9: Akses jaringan di main thread.
Ciri: panggilan Retrofit langsung di Activity.
Masalah: ANR, UI macet.
Perbaikan: gunakan coroutines atau Flow di ViewModel.

Anti-pola Android A10: Rahasia di BuildConfig atau repositori.
Ciri: API key ditulis langsung di build.gradle.kts.
Masalah: kebocoran rahasia.
Perbaikan: gunakan local.properties, gradle.properties lokal, atau variabel lingkungan.

Anti-pola Android A11: Keystore dilacak Git.
Ciri: file .jks atau .keystore ada di repositori.
Masalah: risiko keamanan serius.
Perbaikan: hapus dari Git, rotasi keystore, gunakan manajer rahasia.

Anti-pola Android A12: google-services.json dilacak Git.
Ciri: file google-services.json ada di repositori.
Masalah: risiko konfigurasi Firebase terbuka.
Perbaikan: hapus dari Git, gunakan variabel lingkungan atau file lokal.

Anti-pola Android A13: Dependensi duplikat di banyak modul.
Ciri: setiap modul mendeklarasikan versi berbeda.
Masalah: konflik versi, build gagal.
Perbaikan: gunakan version catalog dan convention plugin.

Anti-pola Android A14: Dependensi melingkar antar modul.
Ciri: modul A bergantung pada B, B bergantung pada A.
Masalah: build gagal, sulit dirawat.
Perbaikan: pindahkan kode bersama ke modul core.

Anti-pola Android A15: Modul fitur bergantung pada modul fitur lain.
Ciri: feature/beranda bergantung pada feature/detail.
Masalah: batas fitur kabur.
Perbaikan: gunakan modul navigasi atau kontrak.

Anti-pola Android A16: Modul core bergantung pada modul fitur.
Ciri: core/data bergantung pada feature/beranda.
Masalah: dependensi terbalik.
Perbaikan: pindahkan kode ke modul yang tepat.

Anti-pola Android A17: Tes instrumen untuk logika murni.
Ciri: tes logika bisnis berada di androidTest/.
Masalah: tes lambat, mahal, rapuh.
Perbaikan: pindahkan ke test/ sebagai tes unit.

Anti-pola Android A18: Tidak ada tes unit.
Ciri: hanya ada androidTest/ atau tidak ada tes sama sekali.
Masalah: regresi tidak terdeteksi.
Perbaikan: tambahkan tes unit untuk ViewModel, use case, repositori.

Anti-pola Android A19: Build varian tidak konsisten.
Ciri: sebagian modul memakai flavor, sebagian tidak.
Masalah: membingungkan, sulit diotomasi.
Perbaikan: tetapkan konvensi varian.

Anti-pola Android A20: Nama resource tidak konsisten.

Masalah: sulit dicari, membingungkan.
Perbaikan: gunakan snake_case untuk resource.

Anti-pola Android A21: Package tidak cocok dengan namespace.
Ciri: namespace di build.gradle.kts berbeda dengan package file.
Masalah: R class tidak ditemukan.
Perbaikan: samakan namespace dengan package atau sebaliknya.

Anti-pola Android A22: applicationId berubah tanpa strategi.

Anti-pola Android A27: Kode mati tetap ada.
